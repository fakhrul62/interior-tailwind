# Interior Tailwind README

## Live Demo
Check out the live project: [Interior Tailwind](https://fakhrul62.github.io/interior-tailwind/)

## Project Overview
**Interior Tailwind** is a modern, responsive interior design website built using Tailwind CSS. It showcases elegant layouts, smooth animations, and a user-friendly interface to highlight various interior design concepts.

## Features
- **Fully Responsive**: Optimized for all screen sizes.
- **Modern UI/UX**: Clean and elegant design.
- **Tailwind CSS**: Lightweight and customizable styling.
- **Smooth Animations**: Interactive and engaging user experience.
- **Static Hosting**: Deployed on GitHub Pages.

## Technologies Used
- **Frontend**: HTML, Tailwind CSS
- **Deployment**: GitHub Pages

## Installation & Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/fakhrul62/interior-tailwind.git
   ```
2. Navigate to the project folder:
   ```sh
   cd interior-tailwind
   ```
3. Open `index.html` in your browser.
